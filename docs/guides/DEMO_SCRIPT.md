# DEMO SCRIPT

## 0. Preparation (Before Demo)
1. Start backend: cd backend; npm run dev
2. Start mobile: cd mobile; flutter run
3. Ensure a user account can authenticate (or bypass mode is configured).

## 1. Authentication (1 min)
1. Show login screen.
2. Sign in and enter the app.

## 2. Map + Exploration (2 min)
1. Show map screen.
2. Tap/inspect districts and explain exploration progression.

## 3. Places Discovery (2 min)
1. Open places list.
2. Search by name and filter by category/district.
3. Open a place detail page.

## 4. Visit Verification (2 min)
1. From place detail, tap Mark Visit.
2. Explain verification workflow and result states.

## 5. Trip Integration (1.5 min)
1. From place detail, tap Add to New Trip.
2. Show prefilled destination and save trip.

## 6. Profile + Achievements (1 min)
1. Open profile.
2. Open achievements and show unlocked/in-progress/locked tabs.

## 7. Shop (0.5 min)
1. Open shop and show product-to-checkout path.

## Closing (Optional)
- Mention backend API coverage, tests, and architecture docs.
